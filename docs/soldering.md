# 焊接指南 · Soldering Guide

V3.0 的焊接顺序、温度参数和检查清单。
Soldering sequence, temperature settings, and checklists for V3.0.

---

## 一、两个需要热板的元件

| 元件 / Part | 原因 / Reason |
|---|---|
| **ESP32-S3-WROOM-1** | 底部整片接地焊盘，烙铁够不到 |
| **TP4056（ESOP-8）** | 底部散热焊盘 + 6 个散热过孔 |

**其余全部烙铁可焊。** / Everything else can be hand-soldered.

---

## 二、焊接顺序（从易到难）

```
① 0603 / 0805 / 1206 阻容      → 烙铁 + 镊子
② SOT-23（S8050）               → 烙铁
③ SOT-23-5（TLV62568）          → 烙铁
④ SOP-8（AT24C02）              → 烙铁
⑤ SOIC-16（DS3231MZ）           → 烙铁
⑥ Micro-USB                     → 烙铁（细尖，0.65mm 间距）
⑦ 直插件（排针、端子、按键、蜂鸣器）→ 烙铁
⑧ ESP32-S3 模组                 → 热板 / 热风
⑨ TP4056                        → 热板 / 热风
```

**最后焊两个带散热焊盘的** —— 减少整板受热次数。

---

## 三、热板参数

```
有铅锡膏（Sn63Pb37）  →  熔点 183°C，热板设 200~210°C
无铅锡膏（SAC305）    →  熔点 217°C，热板设 235~250°C
```

**操作：**

1. 台子升到设定温度，稳定
2. 先在室温下把锡膏和元件摆好（不要在热板上摆）
3. 整板放上去
4. **盯锡膏状态**：灰白 → 变暗 → 变亮、发液体光泽 = 到温
5. 元件会自己“啪”地对齐（表面张力）
6. **立刻把板子夹走**，放瓷砖上自然冷却

> ⚠️ 别只信热板的温度读数 —— 传感器在底部，实测表面可能高 15~25°C。
> 建议用红外测温枪核对一次。

## 四、上电前检查清单

```
□ 万用表量 VBUS 对 GND：不导通
□ 万用表量 5V   对 GND：不导通
□ 万用表量 3.3V 对 GND：不导通
□ 目视检查：无连锡、无立碑、无虚焊
□ ESP32-S3 模组四边引脚都焊上
□ ESP32-S3 模组底部焊盘焊上（镊子轻推不晃动）
□ TP4056 底部焊盘焊上（从背面 6 个过孔能看到锡）
□ Micro-USB 五个引脚无短路（0.65mm 间距，最容易连锡）
```

**四项通断测试通过，再插 USB。**

---

## 五、OSP 注意事项

V3.0 用的是 **OSP** 表面处理。

```
❌ 不要用手指直接摸焊盘（手上的油会破坏 OSP）
✅ 拆封后尽快焊完
✅ 长期存放用干燥柜或真空袋
✅ 焊前用异丙醇轻擦，别用力搓
⚠️ OSP 保存期约 6 个月
```

## 六、工具清单

```
✅ 恒温加热台（250°C 可调）
✅ 细尖烙铁（K 型或 I 型头）
✅ 锡膏（有铅或无铅，配对应温度）
✅ 助焊剂（松香或无卤免洗）
✅ 尖头镊子
✅ 吸锡带
✅ 异丙醇 + 棉签
✅ 放大镜 / 手机微距
✅ 万用表
✅ 红外测温枪（可选，建议）
```

---

## 七、第一上电测试

```
① 不焊 ESP32 模组，先只焊电源部分
② 插 USB，量 3.3V 输出（应该 3.28~3.32V）
③ 量 TP4056 的充电电流（串万用表）
④ 断电，焊 ESP32 模组
⑤ 再上电，看串口有没有启动日志
```

**分步验证，别一次全上。**
