# ESP32-S3 桌面时钟 V3.0

自绘四层板 + ESP32-S3 + NTP 对时 + 网页上传 MIDI 闹钟旋律。

## 硬件

| 项目 | 参数 |
|---|---|
| 主控 | ESP32-S3-WROOM-1-N16R8（16 MB Flash / 8 MB PSRAM） |
| 板层 | 4 层，1.6 mm，OSP，蓝色阻焊 |
| 尺寸 | 81.915 × 72.263 mm |
| 显示 | 0.91" OLED 128×32（SSD1306，I2C 0x3C） |
| 走时 | DS3231（I2C 0x68）+ CR1220 备电 |
| 存储 | AT24C02（I2C 0x50） |
| 电源 | USB-C → TP4056 充电 → TLV62568 降压 → 3.3 V |
| 声音 | 无源蜂鸣器（PWM） |
| 交互 | 4 键 + RST + BOOT |
| DRC | 0 错误 |

## 固件功能

- NTP 自动对时（`ntp.aliyun.com`，时区 `CST-8`）
- 按键设置闹钟，响铃可停
- 网页控制端：`/`、`/api`、`/set`、`/play`、`/stop`、`/ring`、`/upload`
- 网页上传 MIDI 旋律，解析后存 NVS（最多 4096 事件 / 1024 音符）
- mDNS：`clock.local`

## 本次新增工具

| 工具 | 用途 |
|---|---|
| `tools/i2c_scan` | 扫描 I2C 总线，识别 0x3C / 0x50 / 0x68 |
| `tools/rtc_probe` | 识别 DS3231 / DS1307，读温度与走时状态 |

实测结果：OLED、AT24C02、DS3231 全部响应；DS3231 片内温度 30.75 °C，秒寄存器正常递增。

## 已知问题

- **CR1220 备电**：电池座负极下方缺 GND 铺铜，备电未接通；电池曾因短路鼓包，待重新购买并补铺铜
- **DS3231 假货**：立创扩展库购得的一颗曾把 I2C 总线拉死，已更换为优信电子原装
- **LEFT 按键焊盘**：V3.0 板上焊盘已脱落，飞线到模组 23 脚（GPIO21）可用
- **充电指示灯**：热台焊接时受损
