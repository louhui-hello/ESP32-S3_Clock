## V3.0（2026-10-17 下单）

**关键变化**

- 主控升级为 **ESP32-S3-WROOM-1-N16R8**
- 从 2 层升到 **4 层**，叠层改为 信号 / GND / 3V3 / 信号
- 电源链完整化：**TP4056 充电 + TLV62568 降压**
  - 替换掉旧方案的 AMS1117（压差大、静态电流高）
- 增加 **CR1220 备电**，RTC 掉电不丢时间
- 增加 **AT24C02**，存闹钟和配置
- 板载 **无源蜂鸣器**（PWM 驱动）
- 4 键 + RST + BOOT
- TP4056 加 **散热焊盘 + 6 个散热过孔**

**交付参数**

- 尺寸 81.915 × 72.263 mm
- 4 层，1.6 mm，OSP，蓝色阻焊
- DRC 0 错误

## V1.5（2026-10-12 下单）

- 4P 排针（外接 OLED）
