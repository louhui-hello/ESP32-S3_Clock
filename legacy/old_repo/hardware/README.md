# hardware

存放嘉立创EDA 专业版工程导出文件（`*.epro2`）。

导出方式：EDA 中 `文件 → 导出 → 嘉立创EDA 工程`。

> 工程内部名称为 `8266_timer_v2`（历史遗留），内容即为本项目的 ESP32-S3 闹钟板。
